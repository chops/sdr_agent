# Decision log

Owner decisions that shaped the product and the process. IDs are stable; v0.2
corrected some dates and wording after Codex's review, and each correction is
noted in the entry. v0.3 (2026-10-12) adds D-021 to D-109 from the owner's
prep-docs walkthrough and notes where they change D-003, D-008, D-010, D-015,
D-016 and D-020.

Only the owner makes these decisions. Claude and Codex propose options and
recommend one. The "Alternatives considered" column lists options the agents
put forward; it does not quote the owner unless it says so.

**Status values:** *confirmed* (owner decided, as written), *qualified*
(decided, with limits stated in the entry), *proposed* (not yet decided),
*superseded* (replaced by a later entry), *superseded in part* (a later entry
replaces the clause named in the entry; the rest stands).

**Evidence locators:** repository paths are public. "Owner chat" points to the
private Claude session transcript for that date; a sanitized record goes in
git only within the publication policy in [`README.md`](README.md).
"Walkthrough row" points to a row of the walkthrough log,
`docs/product/walkthrough-2026-10-09.md` on branch `owner-decisions` (not yet
merged to `main`), with the commit that recorded the row. The log file is named
for Oct 9; rows 1 to F11 were recorded on Oct 10, and entries use the recorded
date.
