corrected some dates and wording after Codex's review, and each correction is
noted in the entry.

recommend one. The "Alternatives considered" column lists options the agents
put forward; it does not quote the owner unless it says so.

(decided, with limits stated in the entry), *proposed* (not yet decided),
*superseded* (replaced by a later entry).

**Evidence locators:** repository paths are public. "Owner chat" points to the
private Claude session transcript for that date; a sanitized record goes in
git only within the publication policy in [`README.md`](README.md).
