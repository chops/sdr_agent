#+TITLE: Fix: child processes inherited the audit-anchor signing key
#+DATE: 2026-10-07

* Summary
Under =bin/with-secrets SDR_AUDIT_ANCHOR_PRIVATE_KEY -- bin/demo run= every
external process the app launched (ClaudeCLI port, anchoring Git and
OpenTimestamps subprocesses, provenance =git=) inherited the full BEAM
environment, signing key included; every launcher now passes an explicit
environment allowlist (=SdrAgent.ChildEnv=).

* Entity Model

#+BEGIN_EXAMPLE
Entity Model trigger: no
Reason: process-launch environment only; no persisted concept, resource,
policy, lifecycle or action contract changes.
#+END_EXAMPLE

* Root Cause
=System.cmd/3= and =Port.open/2= children inherit the parent environment
except for the names explicitly overridden. Launchers only added or removed
a few names (ClaudeCLI: witness ids and Bedrock/Vertex/Foundry routes; OTS:
the key by name; Git: Git-local variables), so every other secret
(=*_KEY=, =*_TOKEN=, =*_SECRET=) passed through, and the ClaudeCLI and Git
children received the anchor key itself.

* Reproduction
=test/sdr_agent/child_env_test.exs=: runtime-built canary names
(=SDR_AUDIT_ANCHOR_PRIVATE_KEY=, =SDR_CANARY_<rand>_KEY/_TOKEN/_SECRET/_UNLISTED=)
are set in the parent; a real child of each launcher records only the
NAMES of its environment.

* Affected Apps
- [X] Core (=sdr_agent=)

* Affected Modules
- =lib/sdr_agent/child_env.ex= (new) — allowlist builder for =System.cmd/3=
  and =Port.open/2=; base =PATH HOME USER LOGNAME LANG TMPDIR TZ LC_*=;
  secret-looking names removed even if allowlisted.
- =lib/sdr_agent/ai/model_provider/claude_cli.ex= — port env =

  ANTHROPIC_BASE_URL CLAUDE_CONFIG_DIR SSL_CERT_FILE NIX_SSL_CERT_FILE
  NODE_EXTRA_CA_CERTS=) + witness ids; route-variable unsets kept.

  (=SSH_AUTH_SOCK SSH_AGENT_PID GIT_SSH GIT_SSH_COMMAND= + TLS roots).
- =lib/sdr_agent/audit/anchor_sinks/open_timestamps_sink.ex= — wrapper env
  (TLS roots, =TZ=UTC=).
- =lib/sdr_agent/audit/provenance.ex=, =lib/sdr_agent/audit/anchoring.ex=
  (compile-time git) — base allowlist.

* Risks & Considerations
- The ClaudeCLI allowlist is derived from =llm-proxy-shim='s variables and
  Claude Code's needs; it was not exercised against the real CLI (no
  real-call budget). If the owner's Claude Code needs another non-secret
  variable, the real smoke (=:external=) will show it; add it to
  =@child_env_allow= after review. Credentials passed by environment (e.g.
  a token variable) are deliberately removed (ADR-0004: cached local login).
- =GIT_SSH_COMMAND= is passed through as operator configuration.
