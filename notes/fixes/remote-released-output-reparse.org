#+DATE: 2026-11-03

* Summary

returns the result gate's released read (=row.parsed_output=, jsonb, string

* Root Cause
=model.ex= =remote_gate/2= returns ={:ok, read, invocation}= where =read= is
=ReleasedOutput.fetch/2= → =row.parsed_output= (jsonb: string keys). The
in-process path returns the Zoi-parsed atom-keyed output from
=ModelProvider.validate_result/3=. All four consumers use atom access:
- =build_evidence_bundle.ex:78-79= (=output.claims=, then =claim.source= …)
- =score_lead.ex= (=output.evidence_ids=, …)
- =draft_email.ex:45=
- =classify_reply.ex:41=

={:exception, KeyError}= at its first model result (receipt
trope-terminal-20261103.xA9zdXi3/receipt.org 80e3d7cf; root cause
claude-trope-run-keyerror-rootcause-20261103.org 250b2631). The existing
remote end-to-end test accepted either key form (=output["score"] ||
output[:score]=), so it did not catch this.
