* Summary
Build the S7 rows of the reviewed S2 entity model and the Jido agent plane:
the =SdrAgent.Operations= domain (=Operation=, =Failure=,
=Operations.list_attention/1=) with the FKs S3 deferred, the operator-attention

handed to S8; Draft creation is S8 (S2 "Not persisted as their own
entities": the proposal lives in the ModelInvocation's parsed output and its
=draft_proposal= Decision).

Split for review (owner brief: > ~2,500 lines): *S7a* = Operations +
providers + budget persistence + attention side effects; *S7b* (based on
S7a) = agent + signals + actions + flows + Oban worker + golden path.

- *Soft-stop verdict:* PASS (inherited from S2; this plan is not a delta).
- *Implementation choices within the S2 contract* (flagged for the PR
  reviewer; none weakens suppression, approval, idempotency or audit):
  1. *Operation audit.* S2: "AE: create, terminal transitions, operator
     retry/cancel (not heartbeats)". S7 has no heartbeat writes, so every
     Operation write (including =start=) is audited and the resource is
     record-hash verified (=__sdr_audited__=). More audit than required.
  2. *One Failure per condition.* An Operation that fails because its
     AgentRun failed links the run's existing attention Failure
     (=last_failure_id=) instead of opening a duplicate; an Operation failure
     without one opens its own. =failed → discarded= keeps the same Failure.
  3. *Lead → blocked.* The =:block= action itself opens the Failure (class
     from argument =failure_class=, default =run_stopped=; subject the lead)
     in its transaction, so a blocked lead without a Failure cannot exist
     (Codex S5 condition on choice 8). ADM =:retry= (blocked → assigned)
     resolves the lead's open/acknowledged Failures with a system note in the
     same transaction.
  4. *AgentRun → failed | budget_exhausted | system-cancelled* opens the
     Failure and sets =attention_failure_id= in the transition's transaction
     (classes =run_stopped= / =budget_exhausted=; severity critical for
     budget). These transitions become row-locked (=require_atomic? false=,
     =Transition locked?: true=) to set the column; the from-state guard is
     still checked on the locked row. Operator cancel opens no Failure (S2:
     "cancelled by a system actor"). =:retry= resolves the retried run's
     Failure with a system note.
  5. *Daily model-call cap (ADR-0004: 200 per UTC day).* Replaces the
     volatile =BudgetStore=: inside =Agents.reserve_model_invocation/3='s
     transaction, after the run counter is reserved (run row lock, then the
     chain-head lock its audit append takes), the tenant's ModelInvocations
     with =reserved_at= in the current UTC day (=SdrAgent.Clock=) are counted;
     at the limit the whole reservation rolls back with
     ={:error, {:budget_exhausted, :daily}}=. All reservations serialise on
     the chain-head lock, which is held until commit, so two runs cannot both
     take the last unit; lock order (run row → chain head) matches every other
     audited counter write. Attempts are never refunded (failed and unknown
     calls count). The S2 =ModelBudgetDay= row is *not* created: the owner
     brief asks for the count from today's ModelInvocations, which S2 already
     names as the verifier's recomputation source. Config may only lower the
     limit (=min(config, 200)=). *Deviation from the brief:* the brief says
     "America/Denver day per S2"; S2 (=ModelBudgetDay.utc_date=) and ADR-0004
     both say *UTC day*, and S5 choice 14 defers any timezone database to S8.
     S7 follows S2/ADR-0004 (UTC) and reports the discrepancy.
  6. *Claude CLI attestation drift* (=model_attestation_drift=,
     =version_attestation_drift=, =tool_attestation_drift=,
     =mcp_attestation_drift=, =slash_command_attestation_drift=,
     =missing_init_attestation=) fails the ModelInvocation *and* opens a
     critical =provider_error= Failure (subject the invocation) in the same
     transaction.
  7. *Failure message redaction.* No redactor existed;
     =SdrAgent.Operations.Redactor= replaces secret-shaped substrings
     (bearer/API-key/JWT/PEM shapes, long hex/base64 runs, =key=value= pairs
     with secret-looking keys) before insert; the full detail, if any, goes to
     a Payload (=detail_sha256=) after the same redaction.
  8. *Decision kind actors (S3 choice 6).* S7 is the first emitter of
     =campaign_state_check= by the agent (the agent must check campaign state
     deterministically before working a lead, spec §8): AGT is added to that
     kind's actors. No other kind changes; the kind stays deterministic-only.
  9. *Suppression before S8.* The Suppression store is S8. S7 records a
     deterministic =suppression_check= Decision through the
     =SdrAgent.SDR.SuppressionCheck= behaviour; the S7 default
     (=NoStore=) reports =not_suppressed= with =store: none= in the decision
     inputs. S8 must configure its real implementation; the S8 send gate
     re-checks suppression regardless, so no message can reach a suppressed
     recipient through S7.
 10. *Agent stops leads only through S2 transitions.* AGT may not =:stop= a
     lead (S5 policy); =sdr.lead.suppressed= and =sdr.campaign.paused= end the
     run (phase =stop=) with a deterministic Decision; stopping the lead is
     the S8 suppression side effect / an operator action.
 11. *Oban.* One worker (=SdrAgent.SDR.AgentWorker=, queue =research=) runs
     an assignment's AgentRun; the assignment, its run, its Operation, the
     =sdr.lead.assigned= signal event and the Oban job are written in one
     transaction (outbox). =max_attempts: 1=: agent work is never retried
     automatically (ADR-0004 "never retries in a loop"; operator =retry=
     creates a new run). Crash recovery of an interrupted run (=sent →
     unknown=, stale =running=) is S13's Oban restart/idempotency acceptance.
 12. *Jido execution mode.* The agent is evaluated turn by turn with
     =Jido.Agent.cmd/3= inside the Oban job (=SdrAgent.SDR.Runner=); each
     emitted =Emit= directive's signal is appended as a =signal= AuditEvent
     and fed back as the next turn. A live =AgentServer= is not used: Jido
     documents that directives are not a durable queue, and Oban + Postgres
     already own durability (spec §12: Jido persistence restores execution
     state only).

* Implementation Notes

** Further choices made in 4b (flagged for review)
 13. *Root JSON Pointer.* The =qualification= and =draft_proposal= LLM
     Decisions cite the whole parsed output (RFC 6901 pointer =""=). Ash cast
     =""= to nil, which the llm-mode rule refuses; Decision =output_pointer=
     now allows the empty string (=allow_empty?: true=). No schema change.
 14. *Claude CLI fenced JSON.* Running the =:external= test showed opus
     wraps longer JSON in a =```json= fence (S6a's own smoke test also fails
     intermittently on main for this reason). The adapter now unwraps
     exactly one surrounding fence; any other text still fails and Zoi
     validates as before.
 15. *Oban job outcome.* The worker's job completes once the run's outcome
     — success, budget exhaustion, invalid output, crash — is recorded in
     Postgres (run terminal, Operation succeeded or failed→discarded with
     the run's Failure). Only an unrecorded crash leaves an Operation
     =running= (S13 crash recovery).
 16. *No lead block on model failure.* A run that fails on the model
     (invalid output, provider error) opens the run's Failure; the lead
     stays in its phase. =Lead → blocked= is used for the deterministic
     "no accepted evidence" outcome. An operator path to resume a failed
     assignment (new run for the same lead) is not in S7 (see S10/S13).
 17. *Evidence quality.* =evidence_quality= is an LLM Decision per
     extracted claim (S2: "evidence_quality per extracted claim"); when the
     deterministic grounding check fails its outcome is =ungrounded= and no
     claim is written.
 18. *Jido v3 specifics.* Flow steps run in Task processes; the run's
     OpenTelemetry context travels in the caller context and is re-attached
     per action (all rows of a run share one trace — asserted). The S1
     spike and =Jido.AI.Test.MockLLM= were already removed from =lib/= by
     S6a (=65f94be=); nothing in =lib/= references them.
