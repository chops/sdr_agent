* Design
** 1. =Runtime.eligibility/1=
Replace the last arm (=not test_launcher? -> :real_model_staged=) with:
- test launcher → =:ok= (unchanged);
- otherwise, the version binding (below) → =:ok= or =:pinned_cli_version_mismatch=.
The earlier arms (not running, held, not quiescent, shim, pin) are
unchanged and still come first. =status/0= and the Admin card's
"Accepting calls" follow the same function (no UI change; its copy for
=:real_model_staged= is no longer reachable for a pinned server and stays
for the other cases where it is returned).

** 2. Version preflight (condition (1), the missing part) — OQ-E3P-1
Proposed: a no-call, metadata-only binding at resolution and again at the
server's launch: the pinned executable's recorded identity
(=nix/app-claude-cli.identity=, already read by =PinnedExecutable=) must
name the reviewed =ModelProfiles.cli_version/0= (2.1.294); else
=:pinned_cli_version_mismatch=, no reservation. It runs no CLI and makes
no call. The per-call init check stays the authoritative post-launch
check. Alternative (b): run =claude --version= at server start (spawns a
process; no model call) — more evidence, more surface. Codex to rule.

** 3. =ClaudeCLI.staged/3=
Clause order:
1. test launcher → ={:ok, nil}= (unchanged);
2. test-seam builds only: =%{calibration: _}= → the calibration exemption
   (unchanged, first);
3. *new:* a request with *no* =:calibration= key and a pinned server →
   ={:ok, nil}= (ordinary; no launch expectation, so the full ordinary
   =launch_check= applies);
4. anything else (a =:calibration= request in a non-test build) →
   =:real_model_staged= (unchanged).
The pin itself is already checked just before (=pinned_launch=).

** 4. Caller-inventory guard test
An AST walk of =lib/**/*.ex= (as =child_env_inventory_test.exs=) that
fails on any new call site of =ModelProvider.complete/2=,
=ModelProvider.calibration_call/3=, =ClaudeCLI.complete/2=,
=GenServer.call= with a ={:complete, _}= message,
=Agents.admit_launch/3=, =Agents.reserve_model_invocation/3= and
=SDR.Model.call/4= outside today's inventory (above).

and *without* =test_launcher=, plus =PinnedCLI.inject_identity!= and

1. full ordinary path: facade → reservation → launch → validated witness
   (fake CLI =witness= mode, fake proxy) → release → =ReleasedOutput=
   read; for =AgentWorker= (=:assignment= → =:b1=) and a direct facade call;
2. each pre-launch condition refuses with its reason and no launch: no
   server (=:provider_not_running=), pin missing (=:pinned_cli_unavailable=),
   version binding (=:pinned_cli_version_mismatch=), tuple not promoted
   (=:tuple_not_promoted=), store unset/untrusted (=:witness_store_untrusted=),
   gate inactive (=:result_gate_inactive=, via the refuse-only seam), no
   grant (=:no_eligible_grant=);
3. post-launch init drift (fake CLI =model_drift=/=version_drift=):
   charged, withheld, no automatic retry, a critical =provider_error=;
4. after merge with no grant, provider and store healthy:
   =:no_eligible_grant=, no launch;
5. arrival (stage 3 step 5): an unfunded-bucket run (origin set, mapped
   bucket asserted separately) → =:no_allocation=, no launch; a funded
   bucket outside its window → =:no_allocation=; the owner-started run in
   the window reserves;
6. workshop allocation: unusable before =available_from= unless
   =released_at=; overlapping open =:b1= allocations → =:ambiguous_allocation=;
7. grant races (existing C9 race harness): exhausted, expired, revoked
   between reservation and launch, wrong profile, day rollover, held
   reserve;
8. withholding boundaries: witness mismatch, timeout, crash → charged and
   withheld;
9. calibration still needs its exemption: a =:calibration= request to an
   ordinary pinned server without the exemption entry is refused;
10. the caller-inventory guard (positive on today's tree; a synthetic new
    caller in a fixture source fails it);
11. the existing tests asserting =:real_model_staged= for a pinned
    non-test-launcher server (=provider_runtime_test=,
    =model_provider_test= incl. the R0-06 "shipped tuples do not lift
    staging", =claude_cli_test=, =runtime_status_test=) are *deliberate
    old-test changes*, listed exactly in the RED notes, each now asserting
    the next refusal on that path (typically =:no_eligible_grant= or
    =:witness_store_untrusted=), never a weakened assertion;
12. no test makes a real model call (fake CLI only; existing guard).
