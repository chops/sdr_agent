* Design
** 1. =Runtime.eligibility/1=
Replace the last arm (=not test_launcher? -> :real_model_staged=) with:
- test launcher → =:ok= (unchanged);
- otherwise, the version binding (below) → =:ok= or =:pinned_cli_version_mismatch=.
The earlier arms (not running, held, not quiescent, shim, pin) are
unchanged and still come first. =status/0= and the Admin card's
"Accepting calls" follow the same function (no UI change; its copy for
=:real_model_staged= is no longer reachable for a pinned server and stays
for the other cases where it is returned).

** 2. Version binding (condition (1); OQ-E3P-1 ruled (a))
The identity line's reviewed version (Entity delta above) must equal
=ModelProfiles.cli_version/0=:
- at resolution (=Runtime.eligibility/1=, pure, file metadata only):
  refusal before any reservation;
- in the server immediately before each launch (=pinned_launch/1=, every
  queued call passes it, whatever its entry): the reservation is already
  charged; the facade re-reads the still-=reserved= row and fails it
  (charged, never launched), as for =:pinned_cli_unavailable= today.
=Runtime.refusal_message/1= gains a fixed operator message for
=:pinned_cli_version_mismatch=, so no worker or page crashes rendering it.
Boot sha256 verification is unchanged. No =--version= subprocess.

** 3. =ClaudeCLI.staged/3= (must-fix 1)
A request's missing =:calibration= key proves nothing, so the new clause
only *asks* launch admission to treat the call as ordinary; the stored,
locked rows decide (Entity delta). Clause order:
1. test launcher → ={:ok, nil}= (unchanged);
2. test-seam builds only: =%{calibration: _}= → the calibration exemption
   (unchanged, first);
3. *new:* any other request to a pinned server → ={:ok, :ordinary}=; the
   launch then calls =Agents.admit_launch/3= with =ordinary_launch: true=
   and no =calibration_launch:=;
4. a =%{calibration: _}= request in a non-test build →
   =:real_model_staged= (unchanged; clause 3 does not match it).
So a genuinely authorized proof reservation whose request lost its
=:calibration= key reaches clause 3 and is refused at launch admission
(=:ordinary_scope=, from the locked run): no process, no sent transition,
no exemption entry consumed, no calibration launch receipt; the committed
launch-refusal event is expected.

** 4. Caller inventory (must-fix 4)
Extend the existing =ModelProviderInventoryTest= (it already resolves
aliases, grouped aliases, captures and literal =apply/3=, and names its
exceptions by caller module and function) rather than a new scanner:
- add the server message ={:complete, _request, _enqueued_at}= (three
  elements) in =GenServer.call/2,3= outside =ClaudeCLI.complete/2=;
- add =Agents.admit_launch/3= (only =ClaudeCLI.admit/3=),
  =Agents.reserve_model_invocation/3= (only the facade and the test-seam
  calibration console), =SDR.Model.call/4= (only the four SDR actions) and
  =ModelProvider.calibration_call/3= (only the console), each as a
  module/function allowlist, in the same remote/alias/capture/apply forms;
- synthetic positive and negative sources for every enforced form.
Limits stated in its moduledoc: it is a regression inventory of source,
not runtime caller authorization; a function name computed at runtime is
not seen.

* Binding clarifications with the PASS (=cad33c66=)
1. "Nothing written" for a malformed option means no target invocation,
   charge or launch mutation. It does *not* suppress the existing
   =model.launch.refused= append (=record_launch_refusal=) or Guard's
   denial audit; tests never assert a zero total-event count. The option
   parser runs before the target preflight read.
2. Failure outcomes hold only if their persistence succeeds: a launch
   rollback leaves a pre-existing reservation =reserved= (an enclosing
   transaction may also lose its own writes); the facade's later
   reserved-row fail commits in the test only after the holder is
   released. Persistence errors propagate; an uncommitted failure is never
   reported as stored.
3. The ordinary marker stays separate from calibration expectation maps in
   every helper (target checks, =launch_binding=, option forwarding,
   receipt dispatch); it grants no calibration context, exemption or
   receipt.
4. Race and failure fixtures: exact participant blocking evidence, bounded
   joined teardown, restored connection settings, the table holder
   released after the failed query is observed and before the facade
   settles; owned synthetic data only, provenance kept; no real CLI.
