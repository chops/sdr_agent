* Implementation Steps
1. Define request/result contracts, the provider behaviour, and facade that reserves a budget unit, emits a =gen_ai.*= span, invokes a provider, validates every output with the request's Zoi schema, and settles the reservation.
2. Implement a supervised in-memory budget store with 20 calls per run and 200 per UTC day, behind callbacks that S3 can replace with transactional persistence.
3. Implement deterministic Fake fixtures and configure Fake as the default in development and test.
4. Implement the Codex adapter and JSONL stdio transport: initialize with =clientInfo.name=sdr_agent=, verify an existing ChatGPT account with =account/read=, select an available model from =model/list=, capture sanitized version/config/catalog provenance, start a no-tool thread/turn, and serialize calls through one GenServer.
5. Add hermetic tests using a fake app-server OS process plus an =:external= real-server smoke test excluded by default.
6. Amend ADR-0004, remove the S1 spike, update architecture diagrams for the new external integration/runtime flow, and run the full gate.

* Risks & Considerations
- Codex app-server is experimental; parse only the documented protocol fields and retain raw JSON-RPC records for future S3 audit persistence.
- The in-memory budget resets on application restart and is not authoritative; S3 must supply a transactional store before unattended real-model operation.
- App-server may expose executable tools through host configuration. S6a starts a constrained thread, supplies no dynamic tools, uses =approvalPolicy=never= and a read-only sandbox, and treats any tool/approval request as a provider failure.
- Config/account responses may contain sensitive fields. Provenance is built from an allowlist; raw account/config responses are neither returned nor logged.
- Read-only sandboxing does not remove read-capable built-in tools. Real turns
  therefore run with all supported tool-bearing config/features disabled, an
  empty private temporary cwd, and an item-type allowlist that interrupts and
  drains on command/file/MCP/web/unknown items.
