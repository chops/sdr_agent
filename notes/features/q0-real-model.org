#+DATE: 2026-10-07

* Summary
Q0.1 makes the reviewed ClaudeCLI provider usable in the running app: a
runtime selection (=SDR_MODEL_PROVIDER=), one supervised named server, worker
injection with a typed =provider_not_running= refusal, a no-call boot
preflight and Admin status. Q0.3 adds a "Draft awaiting review" call to
action on the lead page. Q0.2 (display only) shows a revision's
=risk_flags= on the draft page.

* Entity Model
#+BEGIN_EXAMPLE
Entity Model trigger: no
Reason: selection is env/config only; no resource, attribute, enum, policy,
relationship or action contract changes. The refusal reuses the existing
AgentRun :provider_error status reason and its run_stopped Failure; the
attestation status is volatile in-memory (ETS) display data, not a record.
#+END_EXAMPLE

* Risks & Considerations
- No no-call attestation probe exists, so drift is detected at the first
  call (as before), not at boot. Boot only checks the launcher exists.
- Returning ={:error, :provider_not_running}= discards the Oban job (max
  attempts 1); the Operation is failed and then discarded with the run's
  Failure, consistent with the job.
- The attestation status is per-boot in-memory; the ModelInvocation ledger
  remains the durable record.
- ReplyWorker is not changed; it reaches the named server through
  =ClaudeCLI.complete/2='s default and fails closed with the typed error
  (reserved invocation failed, run =provider_error=) when it is absent.
