* Design
** Domain function (=SdrAgent.Agents=)
=Agents.mark_terminal_run_sent_unknown(run_id, stale_after_seconds, opts)=.

*Boundary (must-fix 4).* Outside any transaction it goes through
=Guard.run(%{resource: AgentRun, action: :mark_terminal_run_sent_unknown,
subject_id: run_id}, actor, fun)=, like =finish_model_invocation= (so
raw-transaction rejection and auditor denial behave as today). Guard.run is
not the authorization check. Before any read, the function requires
=%Actor{type: :agent_runtime, tenant_id: t}= with =t= a valid UUID; any
other principal (human admin, auditor, another system type, a tenantless
AGT) gets =Ash.Error.Forbidden= and nothing is read or written, even when
the run id matches nothing. A non-UUID =run_id= is =:run_not_found=.

*Grace (must-fix 1).* =stale_after_seconds= must be a positive integer, else
={:error, :invalid_stale_after}= before any read; a direct call cannot
bypass the age rule.

Then one =transact/1= (Kernel transaction):

1. lock the run =FOR UPDATE=, filtered by =id= *and* =tenant_id == t=
   (a new tenant-scoped lock; =lock_run/2= is unchanged). Absent (a foreign
   tenant's run included) → ={:error, :run_not_found}=, no data returned;
2. re-check under the lock: status in =[:succeeded, :failed,
   :budget_exhausted, :cancelled]= else =:not_terminal=; =usage_origin ==
   :proof= → =:proof_run=. =nil= (pre-R0 runs, =agent_run.ex:549-554=) and
   every other origin continue (must-fix 2);
3. cutoff = =Clock.utc_now()= read inside the transaction minus the grace;
4. lock *all* the run's =sent= invocations (=tenant_id == t=,
   =agent_run_id=) =FOR UPDATE= in one statement, sorted =sequence_in_run=
   asc (re-reads status and =sent_at=);
5. *recorded calibration authority (must-fix 3; rev 3)*, checked before
   any mutation for *every* invocation of the run, whatever its status or
   age (a fresh, terminal or unselected row's authority keeps the whole run
   unchanged). Under the run lock no invocation can be added (reservation
   needs a running run and this lock). The rows are read tenant- and
   run-scoped. Each row's evidence comes from a new non-raising
   =Admission.Gate.reservation_authority/1=, which reads the row's original
   =model.invocation.reserved= events (the same tenant, run and subject
   scope as =recorded_tuple/1=, which is unchanged) and classifies:
   - =:no_event= — no reservation event;
   - =:no_tuple= — exactly one event, readable arguments, no (=nil=) tuple;
   - ={:recorded, entry}= — exactly one event with a valid tuple;
   - =:invalid= — duplicated events, unreadable arguments, a non-nil
     malformed tuple, or a failed read.
   Applicability:
   - generation 2 (every row =:reserve= wrote, Fake included): =:no_tuple= →
     no authority; =:no_event= or =:invalid= → =:authority_unbindable=;
     ={:recorded, _}= → =:calibration_authority=;
   - generation 1 (pre-R0; calibration admits only generation 2,
     =Gate.calibration=, =CalibrationRecovery.recoverable?/2=): =:no_event=
     (expected legacy absence) or =:no_tuple= → no authority; =:invalid= →
     =:authority_unbindable=; ={:recorded, _}= → =:calibration_authority=
     (inconsistent, fail closed).
   Any refusal refuses the *whole run* (rollback, nothing written). An
   error is never read as "no authority";
6. for each eligible row (=sent_at < cutoff=; equal or nil skipped):
   =do_update(row, :mark_unknown, %{}, actor)= — the existing action, its
   =[:sent] → :unknown= =Transition= and =model.invocation.unknown=
   =AppendEvent=. *No =settle/2=*, no run write, no Failure, no Operation,
   no release, no lease, no grant write;
7. ={:ok, count}= (0 is a no-op commit); any error rolls back the batch, so
   no partly normalized run or event survives.

All candidate rows (run, every =sent= row) are locked before the first
append (the first =AppendEvent= takes the head), per ADR-0009. Same order
as case (b) and admission. The audit-event reads in step 5 are unlocked
reads of append-only history and take no head.

The generic =finish_model_invocation= / =mark_model_invocation_unknown/2=
are unchanged (no terminal-run bypass or flag). =CalibrationRecovery= is
unchanged. No new marker, recovery route, attestation or cleanup inference.

** Sweeper (=SdrAgent.SDR.StaleRunSweeper=)
- *Sweep-entry check (must-fix 1).* =sweep/1= first reads the grace through
  a new private =stale_after/0=: the =StaleRunSweeper= config must be a
  keyword list and =:stale_after_seconds= (default 1800) a positive integer.
  Otherwise the whole sweep does nothing (no case runs, no write), logs the
  fixed, content-free warning =stale_run_sweeper.invalid_stale_after=, and
  returns =:ok=. Valid configs behave exactly as today. The public
  =stale_after_seconds/0= is unchanged (tests use it).
- *Case (c)*, after case (b): an unlocked prefilter =terminal_sent_runs/2=
  (=ModelInvocation= with =tenant_id=, =status == :sent=, =sent_at <
  cutoff=, =exists(agent_run, status in @terminal and (is_nil(usage_origin)
  or usage_origin != :proof))=), selecting =agent_run_id=, uniq, sorted. The
  prefilter grants nothing; each run goes to
  =Agents.mark_terminal_run_sent_unknown/3= with the validated grace.
- Skips added to =recovered/1=: =:not_terminal= (already), =:proof_run=,
  =:calibration_authority=, =:authority_unbindable=, =:run_not_found=.
  =:invalid_stale_after= is not a skip (the entry check makes it
  unreachable from the sweep; if seen, it is an error).
- Moduledoc gains a case (c) paragraph: ledger-only, counters not
  backfilled, charge kept, not cleanup proof, not retry permission, no
  Failure, calibration authority excluded.

* RED test inventory
New =test/sdr_agent/sdr/terminal_sent_recovery_test.exs= (=AuditCase=,
async false, =reserved_recovery_test.exs= fixtures and style). Every case
goes through the public =StaleRunSweeper.sweep/1= unless it names the
domain function.

1. each terminal status (succeeded, failed, budget_exhausted, cancelled):
   an old =sent= row → =unknown=, one =model.invocation.unknown= event, the
   run row unchanged (status, reason, counters, =updated_at=), no new
   Failure, Operation unchanged;
2. a failed run whose attention Failure is already resolved: stays resolved;
3. one run with two old rows, one fresh row and one exactly at the cutoff:
   both old → unknown, in sequence order; fresh and equal untouched; a later
   pass after aging converts them;
4. origins: =nil= origin (a pre-R0 run, origin written NULL by fixture SQL
   in the test DB) with a generation-1 row → unknown; =:assignment= with
   Fake gen-2 and ClaudeCLI gen-2 rows → unknown;
5. negative: a terminal =:proof= run's =sent= row: no transition, event,
   release, latch, attestation or cleanup inference;
6. negative: a non-proof generation-2 row whose original reservation event
   records a =calibration_tuple= → =:calibration_authority=, nothing
   written for the whole run (a second eligible row in it stays =sent=);
7. negative: a non-proof generation-2 row with a missing, duplicated or
   malformed reservation event → =:authority_unbindable=, nothing written;
8. generation 1: no reservation event → eligible (item 4); one event with no
   tuple → eligible; one event with a valid tuple →
   =:calibration_authority=; a malformed non-nil tuple, duplicated events or
   unreadable arguments → =:authority_unbindable=; nothing written in each
   refusal;
8a. mixed run: an old eligible =sent= row plus a *fresh* =sent= row (or a
   terminal =failed= row) whose reservation records a tuple →
   =:calibration_authority=, the old row stays =sent=, no event;
8b. =Gate.reservation_authority/1= unit cases for each classification,
   including a forced read failure → =:invalid= (no raise);
9. settings, via =sweep/1=: =0=, =-1=, ="1800"=, =1.5=, and a non-keyword
   config container → no write by any case (an abandoned running run and
   an old terminal reservation fixture stay as they are), the fixed warning
   logged with no value, =:ok= returned; the default (unset) still works;
10. queued and running runs: case (c) never touches them;
11. idempotency: a second sweep writes no event; the row is never =failed=,
    =completed=, released or re-sent;
12. =grant_usage/2= for the row's grant: identical before and after;
13. domain function boundary: human admin, auditor, a non-AGT system
    actor and a tenantless AGT → =Forbidden=, nothing read or written,
    including for a nonexistent run id; a foreign-tenant AGT →
    =:run_not_found= with no data and no write; grace =0=/="x"= →
    =:invalid_stale_after=;
14. rollback: a failure injected after the first row's transition (the
    second row's =:mark_unknown= refused) leaves no unknown row and no event.

New =test/sdr_agent/sdr/terminal_sent_recovery_race_test.exs= (real
connections, =pg_blocking_pids= barriers, as the case (b) and C1-03 races):

15. operator cancel of a running run with a =sent= row vs the pass: the run
    lock serializes; the pass converts only once the run is terminal under
    its lock;
16. late settlement (must-fix 5), split by provider and order:
    a. *control:* on a running run, the facade completes normally;
    b. *ClaudeCLI, recovery first:* the row is unknown before the facade's
       re-read; a successful outcome → exactly
       ={:error, :invocation_already_settled}=;
    c. *ClaudeCLI, re-read before recovery:* the re-read sees =sent=, then
       the facade waits on the run lock held by the pass; it gets the
       existing pinned refusal (asserted by exact class), not necessarily
       that atom;
    d. *provider-error outcome:* keeps its own =fail= refusal;
    e. *Fake:* no re-read; the late settle reaches =finish_model_invocation=
       with a stale struct and is refused by the terminal-immutable trigger
       or =BudgetCounter=; the exact existing error is pinned;
    f. *completion fails on the terminal run first*, and a later pass then
       marks the row unknown: both outcomes asserted, no single winner
       assumed.
    In every recovery case: final row unknown, no overwrite, no release, no
    new payload, no success event, no counter change, no automatic retry;
17. lock order: run then every =sent= row before the first append (the
    =reserved_recovery_test.exs= "lock order" style).
